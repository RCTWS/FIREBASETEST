1. حفظ في مجموعات عامة (Public Data)

تتيح مشاركة البيانات مع جميع المستخدمين الذين يزورون التطبيق. مفيدة للمنشورات العامة، لوحة المتصدرين، أو المحتوى التشاركي.

Path: /artifacts/{appId}/public/data/...
🔒

2. حفظ في مساحة خاصة (Private Data)

تُحفظ البيانات مرتبطة حصرياً بـ `userId` الخاص بك ولا يمكن لأي مستخدم آخر رؤيتها أو تعديلها، مثل الملاحظات الشخصية أو الإعدادات الخاصة.

Path: /artifacts/{appId}/users/{userId}/...
⚡

3. المزامنة اللحظية (Real-time Sync)

باستخدام `onSnapshot` يتم تحديث واجهة المستخدم تلقائياً فور حدوث أي إضافة أو تعديل أو حذف في قاعدة البيانات دون الحاجة لإعادة تحميل الصفحة.

Listener: onSnapshot() API

✍️ إضافة تجربة جديدة

جرب كتابة بيانات واختر نوع الحفظ لمقارنة السلوك

ℹ️ معلومة تقنية للمبرمج:

المشروع مبرمج بحيث يمنع استعلامات `orderBy` المركبة لتفادي أخطاء الفهرسة (Indexes) في فايربيز، ويقوم بالفرز والفلترة بكفاءة عالية داخل ذاكرة المتصفح.
